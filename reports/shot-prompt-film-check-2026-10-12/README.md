# 单镜提示词新写法成片验证（2026-10-12）

验证对象是 commit 1d0a9f8（分支 `feat/shot-prompt-skill`）的单镜视频提示词新写法。文字回放已经做过，见 `reports/shot-prompt-ab-2026-10-12/`；这次是用真实视频模型出片，看三件事：①「在第N秒的地方，切镜头」「第N秒起，镜头不切换」在成片里有没有被照做；②站位与分镜是否一致、动作有没有安错角色；③角色是否对上参考图。

## 结论

**差不多。** 切点方面，新写法在成片里和旧写法一样好：8 条全部切对，A04 4/4 只切一次，A05 4/4 不切；A04 切点误差平均旧 0.46 秒、新 0.44 秒。站位与动作归属两边也一样：左右站位、谁做什么全对。剩下的问题两边都有（小白子被叼尾巴拖着跑没演出来、孩子没藏到只露双眼、多出或少了角色）。新写法这批略多，但每组只有 2 条，不足以说更差。在这两个镜头上，新写法没有显出成片层面的优势。

原因之一是这两个镜头分不开两种写法。旧写法本来就按时段写「0—3秒，固定中景……3—7秒，固定全景，机位移到晾衣杆周围」，Seedance 2.0 照样在 3 秒左右硬切。A05 旧写法写「3—6秒（中景，轻微横摇……）」，也没有被切开。文字回放里最能拉开差距的地方，是旧写法不区分切与不切、新写法写错过的那几处（A03@2.5，以及有歧义的 A01@4、A02@3.5、A07@6），这次都没测。

## 怎么看的

- **盲评**：每镜 4 条随机编号（A04-X1…X4、A05-X1…X4），先按编号看片、写下记录（`blind-assessment.md`，写于揭盲之前），再打开对应表 `…/blind/mapping.json`。

- **站位、动作、角色**：看每秒 4 帧的拼图，有疑问的段落再按 8 帧/秒或原始帧放大。拼图与放大图都在 `…/analysis/<编号>/`。
- **声音**：我听不到声音，只能看频谱图，再用用户装的 whisper（base 模型）转写。base 模型在这种短片上很不可靠：A04 几条转出来都是幻听的单字，只当弱证据。
- **标注口径**：
  - A04 应在第 3 秒切一次：前段固定中景，后段固定全景。
  - A05 不切：0–3 秒固定中景，3 秒起轻微横摇随鹅到墙根。
  - 切点与预期相差 1 秒以内算「大致对」。

## 与参考图有关、不能算到写法上的问题

- **小白子的服装与提示词冲突**：用户给的小白子图是角色本身的造型，浅灰紫长发、光环、兽耳、蓬松灰尾巴、蓝围巾、黑色西装外套，没有分镜登记外观里的企鹅造型软帽和企鹅披身。8 条里小白子都按参考图出现，没有穿企鹅服。素材清单写着参考图是「长相与服装的唯一依据」，照图是对的。
  - A04 旧 #2 鹅脚边多出的小企鹅，很可能就是提示词里「企鹅小尾巴 / 企鹅软帽 / 企鹅披身」与参考图冲突的产物。
  - A04 旧 #1 里鹅叼住的是参考图上那条蓬松灰尾巴，这个动作反而演出来了。
  - 这些影响新旧两边相同。
- **画风跟着参考图走**：8 条成片都是小白子、小鲸鱼三视图那种 Q 版大头画风，不是分镜签发的「日系 2.5D、千与千寻动漫风格」。即梦生成的奶奶、大白鹅偏 2.5D，进了成片也被画成同一种 Q 版风格。两边相同。
- **奶奶基本只有背影**：A05 四条都从椅背一侧拍，奶奶背对镜头，看不到她说话的嘴。台词说话人只能靠时间对上挥扇来判断，只有新 #2 能看到她转头朝鹅。

## 局限

- 每镜每种写法只有 2 条，差 1 条就是 50% 的差别。上面新写法略多的偏差（主要是 A04 新 #2）在这个样本量下分不出是写法造成的还是随机波动。
- 只测了 Seedance 2.0 标准版。MiniMax H3 按用户决定没测。
- 声音只看了频谱和 whisper base 的转写，台词内容与说话人判断都是弱证据。
- 横摇起点是按每秒 4 帧的拼图估的，误差约 ±0.25 秒。
- A05 关掉了上一镜抽帧。项目默认对「承接上一镜」的镜头会附抽帧，带抽帧时的表现没有测。

## 需要用户决定的事

1. **新写法要不要继续作为默认。** 这次在两个镜头上没有看到成片层面的好处，但也没有坏处。写稿输出 token 约为旧写法的 2.6 倍、耗时约 2.5 倍（见文字回放）。文字层面的改进（不自编站位、多角色时点名不用代词）是实在的，只是在这两个镜头的成片上没有显出来。
2. **要不要再花一轮钱，测能拉开两种写法的镜头。** 例如：旧写法只写时段、而分镜是「中近景接横移跟拍」的 A03@2.5（文字回放里新写法写错过一次），以及有歧义的交界 A01@4、A02@3.5、A07@6。也可以考虑带上一镜抽帧的默认设置，或者加测 MiniMax H3。
3. **小白子的造型怎么统一。** 是给一张带企鹅软帽、企鹅披身的小白子参考图，还是改分镜里登记的外观（去掉企鹅装）。现在提示词与参考图打架，至少在 1/8 的成片里多出了一只企鹅。
4. **混用不同画风的参考图是否可以接受。** 用户的三视图是 Q 版，即梦出的是 2.5D，成片统一成了 Q 版，没有按分镜签发的画风。
