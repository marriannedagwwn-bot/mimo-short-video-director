MiMo 在别的故事上也被拦过：10-19 的 5 次不重复的首次审阅里有 2 次被拦，都靠重试救回。一次漏了顶层 `guidance`、把内容并进了 `strengths`；一次把引用的键写成 `text`（照抄了输入里 `{id, text}` 的标注格式）。

## 失败原因

1. **两个同名字段，类型不同。** 顶层 `guidance` 是字符串数组，items 里的 `guidance` 是一个字符串。输出模板里 items 那一格写的是「修稿关注点、需保留内容；由修稿者自行选择具体改法」，列了好几件事，模型就写成了列表。Opus 有问题可报的调用里 5/9 中招，Sonnet 1/3，所以这不是 Opus 独有的毛病，只是 Opus 几乎每次都有问题可报。
2. **诊断没说清错在哪。** 拦下数组时的诊断是「reportedProblem / guidance 非空」，可数组明明非空，诊断从头到尾没说「必须是一个字符串，不能是数组」。重试碰运气改对了 4/5 次。回放 #4 重试时又写成了数组，这一步失败。
3. **重试话术是给设计分镜写的。** 共用的 `storyboardRetryPrompt` 让模型「优先调整片段怎么分、各段多长、beat 怎么切」，和审阅无关。
4. **漏字很少见。** 分镜里「画右」出现 47 次，「画面右侧」只有 1 次，漏字的正好是那一处：模型是凭记忆往常见写法上抄的。Opus 47 条引用里只错这一条。重试没有把上一次的原文发回去，所以每次重试都是重写一整份审阅，也就重新承担一次漏字的风险。
5. **选 Opus 时要过两道审阅。** Opus 几乎每次都报问题，于是会接着修订；修订真改了正文就再跑一次终审复查，用的是同一份提示词和校验，风险一样。按每道 4/6 粗算，两道都过只有一半左右，还没算修订那步。样本小，只能当量级参考。

另有一条只出现过一次的观察：回放 #5 第一次报了 2 条问题，重试却 0 条通过。分不清重试是不是在把模型往「少报」推。

## 可选做法

| 做法 | 改哪里 | 能解决什么 | 代价 |
|---|---|---|---|
| A. 诊断写清楚 | `validateStoryboardReview` 的 reason 写明哪个字段、应是什么类型，一次报全；审阅用自己的重试话术。判据一字不改 | 所有模型的重试更准（#4 那种重试仍写错的情况） | 小。第一次失败率不变，Opus 还是约 6 成要多花一次调用（约 $0.23、1 分钟） |
| B. 改提示词措辞 | 输出模板写明 items 的 guidance 是「一段话」、quote「从 text 原样复制」 | 可能降低数组写法 | 默认的 MiMo 也会受影响，要连 MiMo 一起回放。仓库里的记录是措辞类改动常常不起作用 |
| C. Claude 审阅带结构化输出 | 派生一份 Claude 支持的 Schema（只用 object / array / string 和 `additionalProperties: false`；条数上限、非空、逐字仍由服务端校验）；Claude 客户端只在拿到这份 Schema 时发 `output_config.format`，其余阶段请求体不变 | 按构造消除数组写法和键名写错，也就是 Opus 6 次失败里的 5 次。漏字仍靠重试 | 中等，要先进 Plan 模式：改 Claude 客户端、新增 Schema 文件、两道审阅传参、golden 测试、更新 10-19 文档里「第一期不发 output_config.format」那条。官方文档写明它能和流式、自适应思考一起用，但要实测：Opus 5 次约 $1.2 |
| D. 审阅单独选模型 | 模型设置新增阶段键：页面、阶段默认值、token 上限、任务快照、文档 | 换成 Sonnet 或 MiMo 后这一步更容易过 | 改动最大。而且 Sonnet、MiMo 能过主要靠一条不报，蜗牛那条分别只报出 1/6、0/3，等于放弃了 Opus 审阅最有用的部分 |
| E. 维持现状 | 不改 | — | 选 Opus 时，完整分镜大约一半会卡在两道审阅上。失败一次，前面花的约 $1.3–1.9 就白费 |

不放宽逐字核对，也不为「画右/画面右侧」这一个样本加规则。

## 建议

**C + A。**

- C 按构造消除 Opus 的主要失败。仓库里有过同样的先例：MiMo 的候选、设计分镜接 json_schema 后，结构失败归零。
- A 很便宜，对所有模型都有效，能补上 #4 那种重试仍写错的情况，而且不改判据。
- 不做 B：措辞类改动不可靠，还会动到默认的 MiMo。
- 不做 D：Opus 的价值就在审阅能挑出问题。

做 C 之前先进 Plan 模式拿方案；做完用这个脚本回放 Opus 5 次（约 $1.2）验证。
