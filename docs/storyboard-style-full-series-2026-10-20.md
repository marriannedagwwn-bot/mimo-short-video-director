- 《咕嘎和蜗牛》：27 段、276 秒、81 镜。

两份都放在仓库外：`/Users/qinfen/Documents/mimo-director/` 下的 `请对我凶一点-第一章-分镜-全集规则.md`、`咕嘎和蜗牛-分镜.md`。

用户看过说很好，要求：把这套写法接进 4.0 分镜，调到软件出的分镜和手写版一样；模型也可以用 Opus 5.5。

## 全集推翻或修正了第 1 集的哪几条

| 第 1 集版本写的 | 全集结论 | 现在怎么写 |
| --- | --- | --- |
| 一般 2–3 秒一镜 | 全剧平均约 4 秒；有台词 4.7 秒，只有反应声 2.6 秒，空镜 2 秒；快慢跟着「在干什么」走 | 平均约 3–4 秒；有台词 4–5 秒，反应 2–3 秒，空镜 2 秒；动作快、对话和真心话慢 |
| 反应镜头多给听的人 | 单人近景多数给说话的人 | 听的人只在这几种时候给：一句话的落点、过肩时说话人背对镜头、长反应 |
| 开场先给 1–3 个由远到近的空镜 | 只有 4 集这样开 | 按场景选开法：外观空镜、只拍脚、道具、声音先到，或直接给人 |
| 撞倒不拍过程，下一镜人已经倒地 | 撞上那一镜里被撞的人先僵住，倒下放在下一个固定全景里 | 照全集写法 |
| 出画后留空约 1 秒 | 0.3–1 秒；画里有别人就停在留下的人身上；4–5 秒以上表示过了很久 | 照全集写法 |

第 1 集版本里没有、手写时用得最多的几样，这次补进去了：

- 换天用一组固定的空镜，顺序不变。
- 场内跳时间：硬切一个无声的物件空镜，或在同一机位溶镜。
- 同一件事第二次发生时，用同一构图再拍一次，第二次更短，不再给反应。
- 揭底的镜头本身不放人声，那一声放在揭底前一个镜头的末尾。
- 冷场。
- 对话用一个固定主镜头撑住。
- 真心话慢—快—慢，关键的一拍给手，说完马上回到日常。
- 心动的那一拍不出声。
- 人声写明放在镜头的什么位置：开头、末尾、跨切点、画外。
- 写明哪些地方不放人声：揭底镜、心动、跳时间的空镜、落水、挨打、跑完累倒的结果镜。这些 beat 的 soundDesign 写「无人声」。

## 改了什么

| 位置 | 改动 |
| --- | --- |
| `directorGuidance`（`src/storyboard-prompts.js`） | 整段换成全集写法，分成这几组：镜头怎么切 / 一场怎么开、怎么收 / 人物进出 / 动作 / 笑点 / 对话 / 心动和真心话 / 声音怎么写。写法示范保留「角色甲乙」那段，另加一段「角色丙丁借东西」，演示对话主镜头、揭底无声和同构图重复。「不能丢的约束」与提交前自检逐字不动 |
| 同上，第二轮 | 节奏那条加一句：总时长紧、要演的事又多时，先删掉次要镜头、把顺手的动作合进相邻镜头，不要把每个镜头都剪短；安静、慢的段落一个片段 2–3 个镜头就够（依据见下面第一轮的数字） |
| 冷场和对话示范 | 写成「再接剧情里的下一句台词」或「由最冷静的人接剧情里的下一句话（没有台词就只给反应）」，不写「冷冷说一句」。原因：锁台词的 Run 不能新增台词 |
| `storyboardReviewPrompt` | 「不当错误」的清单补上这几项：写明「无人声」的揭底镜头或空镜、冷场里的静默、与前面同一构图的重复镜头、跳过时间的物件空镜、背景换成角色图案的镜头 |
| `shotPrompt` | 加三句：camera 写了与前面某镜同一构图的，照那一镜的景别和机位写；背景换图案、头顶冒符号、溶镜这类画面效果，照 visibleAction 写；soundDesign 写了「无人声」的 beat，不写任何角色人声 |
| 测试 | 重算 `storyboardPrompt` 的金标准哈希；逐字短语改成全集写法的关键句；第 1 集版本里被推翻的 7 句改成反向断言；审阅与单镜写稿新增的句子各加断言 |
| 回放脚本 | `storyboard-design-ab.mjs` 与 `claude-storyboard-compare.mjs` 各补 5 个表面计数，口径和手写版一样：每段最多几个镜头、特写占比、写明「无人声」的 beat、写明同一构图的 beat、有台词 beat 的平均秒数 |

以下这些都没动：`baseStoryboardPrompt` 的 1–10 条、方向句、锁台词锚点句、输出协议、校验器、Schema、固定的无配乐句、Claude 客户端、默认模型。

## 生产路径：Opus 5.5 跑完整分镜

测试服务用 `real-check`（端口 4188，视频密钥全部清空），在页面上走「从剧情开始 → 粘贴完整故事」，贴《咕嘎和蜗牛》，剧情时长选 90 秒。

**拆镜头先失败了两次，都是 MiMo 的问题**：
- 第一次：`/characterBible/helpers/0/identity` 多写了一个字段。
- 第二次：`careRecipient` 写成了 `null`。
- 两次都把说了台词的奶奶漏掉了，没有登记进角色表。
- 拆镜头这一步只调用一次、不重试，所以都整步失败。这是上游的问题，不在这次改动范围内，只记在这里。

第三次把拆镜头换成 Claude Sonnet 5.5，通过了：4 场，90 秒。

**4.0 分镜在模型设置里选 Claude + Opus 5.5，结果：**

| 步 | 结果 |
| --- | --- |
| 设计分镜 | 第一次就通过：12 段、98 秒、40 镜 |
| 审阅分镜 | 两次都被拦：第一次把某条意见的 `guidance` 写成数组（应该是一句话）；第二次引用原文漏了一个字（原文「朝画面右侧爬」，写成「朝画右侧爬」，`STORYBOARD_REVIEW_EVIDENCE_NOT_VERBATIM`）。整个分镜任务失败 |

- 只有两次失败、两种不同的形状，还说不清该怎么改。

**逐份读到的**

- **第 1 集写法的 MiMo**：没有一处写「无人声」，也没有同构图重复。揭底镜照样配叫声，跳时间也没有用无声空镜。
- **全集写法的 Opus 与 MiMo**：几份都用上了手写版那几招：
  - 试步用同一个贴地构图拍两次，第二次更短。
  - 托脸 → 换一只翅膀 → 趴下，放在一个固定长镜头里，或者用同一构图连着切。
  - 先点头两次再睡着，睡眠呼吸约 1.5 秒一次。
  - 跳时间用同机位溶镜，那一镜写「无人声」。
  - 醒来是弱鼻音加两下急吸气，正好对上睁眼。
  - 「空石板」「鞋面上的蜗牛」两个揭底镜都是无人声，倒吸气放在前一镜的末尾。
  - 人出画后，镜头停在留下的蜗牛身上。
- **Opus 第二轮 #2** 的最后一镜回到第 3 片段开头那个大全景机位，和手写版一样首尾同机位。
- **MiMo 的视角镜头一直是 0**：第 1 集写法和全集写法都是 0。这和 10-19 的《鲸鱼风筝》不同，那次是 2，这个故事里看东西的时刻其实不少。

**为什么有第二轮**：第一轮 5 份全集写法的输出，平均每镜都在 2.5–3.4 秒，比手写的 3.4 秒快。原因是故事被压到 90 秒左右后，模型倾向于把每个镜头剪短，而不是少拍几个镜头。于是加了上面那一句。

第二轮的效果：

- Opus 两次从 2.5–2.6 秒放慢到 2.7–2.9 秒，有台词镜头 3.3–3.5 秒，和手写的 3.5 秒一致。
- MiMo 两轮都在 2.6–3.4 秒之间跳，看不出这句规则有作用。
- MiMo 那次时间轴失败，是加法算错（几个 beat 的秒数加起来没凑满片段）。生产路径里会带诊断重试一次，10-19 Haiku 也出现过同样的错。

到此停下，不再为了追数字继续加规则。
