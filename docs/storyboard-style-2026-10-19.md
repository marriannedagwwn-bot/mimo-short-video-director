# 分镜写法替换（2026-10-19）

## 起因

用户让 Claude 拆《天使降临到我身边》第 1 集的分镜与人声写法（例：0:09 跑上楼梯的脚部特写配急促喘气、被扑在身上时的闷哼、空镜头与切换规则），再按这套写法给《鲸鱼风筝》手写了一份分镜。用户看过说「符合我的要求」，要求把这套写法加进视频工作流、替换现在的规则。

拆片笔记和手写分镜放在仓库外（`/Users/qinfen/Documents/mimo-director/分镜学习笔记-天使降临到我身边第1集.md`、`鲸鱼风筝-分镜.md`），这里只记规则怎么进的工作流和验证结果。

## 用户定的三件事

1. **只换创作写法**。有校验器或实测依据的硬规则原样保留：片段 4–15 秒整数、总时长窗口、进出画面方向（第 6、8 条，2026-10-13）、一句台词不跨片段、场次追溯（第 9 条）、输出格式、锁台词。校验器不动。
2. **人声写进现有的 `soundDesign`**，点名是谁发出。不加 Schema 字段，不写成台词。这样「粘贴完整故事」锁台词的 Run 也能加人声；角色参考声音只发给 `dialogue` 里的说话人，只出人声的角色不会被附上样音。
3. **验证**：文本回放加 2–3 段成片。

## 改了什么

| 位置 | 改动 |
| --- | --- |
| `directorGuidance`（`src/storyboard-prompts.js`） | 整段换成「分镜写法」：一镜一 beat、每个 beat 至少 1 秒且用整数秒、不写 1 秒以下的快切；节奏（动作和笑点 1–2 秒，一般 3–4 秒，对话可 6–12 秒一镜到底，一个片段一般 1–4 个镜头）；空镜头（开场由远到近、换天换地点、用人物的东西交代人物、来人前先拍空门口，空镜 beat 的 characters 为空）；先局部后脸；大动作拆起中落三镜、切点在动作中间、放同一片段；撞倒不拍过程；笑点「期待的脸 → 揭底特写 → 反应的脸」；出画留空约 1 秒、先空后入；反应镜头多给听的人；首尾可同机位。声音：人声写进 soundDesign 并点名（跑→喘气，被扑被压被撞→闷哼，被挤→闭嘴的低闷声，犯困→鼻音，起床→哈欠，开心做事→哼歌，看到不妙→倒吸气，着急→叹气，害怕→哭腔；主角开场几秒内出声）；人声不是台词，锁台词时也能加；声音先于画面只在同一片段内部；空镜和新地点写环境声。 |

| `storyboardReviewPrompt` | 不当错误的清单补上空镜头、出画后的留空、先给局部再给脸、soundDesign 里的角色人声。修订提示词不动。 |
| 测试 | `storyboardPrompt` 金标准按同一输入重算；新增断言锁住写法关键句、保留的四条约束、锁台词版同样生效、审阅新增的容忍项、写稿提示词的三句。 |

## 没做的事

- 不加 Schema 字段、不加确定性判据：人声写没写、写得对不对，空镜和局部用得对不对，都要语义判断，不建词表。
- 不改校验器，不改固定无配乐句。那句「只保留现场环境声与动作声」可能让视频模型连人声一起去掉，这次只在写稿指令里说明人声照常保留，成片验证专门看人声。
- 不碰第 6、8 条的方向句。

事先定的线：新写法一次过判据不少于旧写法（8/8 全过）；锁台词时改动台词 0 条（达到）；没有不到 1 秒或非整数的 beat（达到）；开场有空镜（新写法 3/4）；跑、被扑、被挤、犯困这类时刻在 soundDesign 里点名人声（逐份读，见下）；方向不比 10-13 差（逐份读，方向句照常写出）。

逐份读到的：

- **大白鹅**：新 #1 开场由远到近三个空镜，最后一个空镜先传出小白子的哼歌；院门先空着、门轴声先于画面，再让大鹅进来；逃跑整段写「急促的喘气（一呼一吸）」；威吓前写倒吸一口气；日落用空镜跳时间。新 #2 开场直接给人，但同样写了哼歌、门外先传来蹼掌声和「嘎」、被叼住的惊叫、小鲸鱼的哭腔「鲸鲸…」。旧写法两份都没有空镜，人声只零星写到。
- **鲸鱼风筝**：新 #1 门先空着、门外先传来急促脚步与喘气，再推门；新 #2「小白子的脚、书包带、围巾与怀抱的风筝卷先入画，脸尚未看清」，摇肩膀时写「小鲸鱼被摇时闭着嘴的低闷『嗯…』垫在下面」。旧写法两份都没有喘气和闷声。
- **新写法加的叫声**（「鲸鲸」「咕嘎」这类）都写在 soundDesign 里并注明「非人话」或「非台词」，没有进 dialogue，所以台词条数与原文一致。

## 生产路径与成片

在 film-check 测试服务（端口 4194，`runtime/demo-runs/film-check`）用「粘贴完整故事」跑《鲸鱼风筝》：角色边界 → 拆镜头（2 场、约 90 秒）→ 4.0 分镜（设计、审阅、修订、终审全流程，新写法），得到 11 段 91 秒。开场两个空镜（小屋外观 → 门窗），屋里的碗筷和蒸汽声先于屋内画面；门开之前先传来脚步与喘气；推门冲进来全程喘气；摇肩膀写闭着嘴的「嗯嗯」；出画留空约 1 秒再回来；风声先于风筝飞起。

结论：

- **人声这条路通**：分镜写进 soundDesign 的人声，单镜提示词 3/3 都点名写出，成片 3/3 都出了对应的声音。固定无配乐句没有让人声被去掉（3/3）。时间上有 1–2.6 秒的偏差。
- **切点提前**仍在（A05 两刀各早 1.5–2 秒），与 `docs/待解决项.md` 第 23 条第 9 点同一个现象，这次改动没有碰它。
- **A05 的画面问题**（摇得轻、道具变样、角色站起来）是视频模型没照提示词做，提示词里写的是电饭锅、仍坐在凳上。
- **样本小**：每段只出 1 条，一份分镜、两个故事的文本回放。
