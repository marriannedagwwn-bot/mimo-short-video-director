### 抓到的

- **V1 退回原片骨架**。骨架重合 **75**（越过换皮线 70），事件链逐条锚定：
  5 件关键事件里 3 件 `same`，`rewardSource` / `rewardHandling` / `endingShape` 全部 `same`。
  判语：「核心高潮和结局的因果链『外部奖励→转赠长辈』与原片完全一致」。
  ChatGPT 的说法是「捐衣服→阿姨认可→小红花→送奶奶」与「修书→阿姨认可→贴纸→送奶奶」本质相同。**同一个判断。**
- **V1 物理不成立**（手心温度＋吹气修补散落书脊）。判成 `tool_misuse` 因果断裂 + `causalLogic` **BLOCKER**。
- **创意简报太死**，而且结论方向与 ChatGPT 一致：
  报告写「nonNegotiable 的『外部奖励转赠长辈』只适用于原片的捐赠结构，
  对生活片段型候选强行加入会破坏自然感（如 V1 的物理逻辑崩坏），
  建议改为『将美好体验、劳动成果或外部认可分享给亲密关系人』」。
  ChatGPT 写的是「真正应该保留的是：主角的行为产生一个具体结果，
  这个结果最终让她与重要关系对象之间出现一次可见、自然的情感连接」。
- **批次未收敛**（`converged: false`），理由与 ChatGPT 的「这一次四个选题终于各说各的话」一致。

### 没抓到，或判反了

1. **V1 的所有权逻辑完全没提**：图书馆的旧绘本凭什么送给奶奶。
   全文检索「所有权 / 图书馆的书 / 归属」**零命中**。ChatGPT 把这条列为 V1 的**首要**问题。
2. **V3「芙芙猫为什么睡纸箱」没提**。它是固定搭档，设定上不该住在院子里的纸箱。

# 第二次回放：三处修复之后（同一个包，同日）

按第一次暴露的三条问题改了契约与提示词，再跑同一个包。
一次调用、无重试、141 秒、prompt 13416 + completion 13271、**¥0.64**。
原始报告：`选题终审-第二次真实回放-捐旧衣服包.json`。

三处修复：①新增缺陷类型 `ownership_or_authority`，并在 `causalLogic` 里写明
「角色修改、拿走、赠送、销毁或长期占有一件物品时，必须检查它有没有处置权或谁许可过」；
②新增 `setting_assumption`（**封顶 MAJOR**，有确定性闸门），并问一句「这个候选是不是偷偷
引入了上游从没建立过、但会明显改变角色关系理解的背景事实」；
③新增 `physicalAssumptions`：物理机制不许二选一，必须区分**明确成立**与
**依赖未说明条件才能成立**，后者要写出依赖什么、不成立时画面上会怎样。

## 修复三：物理机制——**这条明确有效，而且超出预期**

四个候选各写了一条，判得都对：

| 候选 | 机制 | 判定 |
| --- | --- | --- |
| V1 | 用手心温度捂平起皱的纸张 | `unlikely` —「单纯手温无法提供足够的热量和湿度」 |
| V2 | 用玻璃罐捕捉并保存阳光光斑 | `conditional` —「必须作为角色的童趣想象成立；**如果画面表现罐子里真的发光，会破坏物理常识**」 |
| V3 | 用胶带将湿落叶贴在湿纸箱上防水 | `unlikely` —「胶带在湿润表面无法产生足够粘合力」 |
| V4 | 面团在蒸笼中受热发酵膨胀 | `established`（正确地没有大惊小怪） |

**V3 那条正是第一次判反的。** 这次不仅判对，还顺带报出一处因果断裂：
「beat 1 下阵雨躲在屋檐下，beat 3 却去院子里收集落叶」——第一次完全没提。

**V2 那条是意外收获**：它独立写出了 ChatGPT 当时的那句叮嘱——
「千万不要让后面的 FullStory 真把『阳光被物理封进玻璃罐』当成魔法事实」。
两边的措辞不同，指的是同一件事。

## 修复二：背景设定——生效了，但命中的不是原来那条

`setting_assumption` 立刻被用上，判在 V1：「奶奶在 beat 5 突然出现在图书馆长椅上，
前文未交代其在此处的背景事实」，严重度 MAJOR（符合封顶）。**形状完全正确**——
它就是「候选偷偷引入了一个上游没建立过的背景事实」。

但 ChatGPT 原本指的那条（**芙芙猫为什么住院子纸箱**）**这次仍然没被点出来**。

## 修复一：所有权——**这次回放没能检验它**

`ownership_or_authority` 一次都没被使用，全文检索「所有权 / 归属 / 许可」零命中。

但**不能据此说规则无效**，因为这个案例本身是边界情况：V1 的第 2 拍写的是
「管理员阿姨表示这本书太旧了**只能当废纸处理**，小白子紧紧抱住绘本，选择把它留下来自己修补」。
ChatGPT 自己就写过那个例外——「除非管理员明确把它作为淘汰书赠送给她」。
被宣布作废的书被留下来，处置权问题确实弱得多。

（一处反证仍然存在：第 6 拍的台词是「以后我每周都**来**给它讲故事」，
暗示书还在图书馆——那与「已经送给奶奶」有张力。评审两次都没碰这一点。）

**结论只能是：这条规则至今没有被一个清晰的正面案例检验过。**

## 代价：分数整体收缩，而且很可能是这次改动造成的

| | 第一次 | 第二次 |
| --- | --- | --- |
| 总分 | 5.98 / 8.70 / 7.56 / 8.12，**极差 2.72** | 6.73 / 8.06 / 6.73 / 7.83，**极差 1.33** |
| 首选 V2 | 8.70 · **pass** | 8.06 · revise |
| 排名 | V2 → V4 → V3 → V1（与 ChatGPT 一致） | V2 → V4 → **V1 → V3** |
| 批次收敛 | `false` | **`true`**（四个共用「发现日常小物件 → 童趣改造 → 与亲密对象分享」） |

**十一维里九维的极差都变小了**，只有 openingHook 与 productionFeasibility 持平。

而且能看出一条具体的因果路径：V2 的 `productionFeasibility` 从 9 掉到 **7**、
`causalLogic` 从 9 掉到 8，**恰好对应它那条被判 `conditional` 的玻璃罐机制**。
也就是说，新增的物理审视确实压低了分数——**它买到了 V3 的正确判定，
代价是把整体分数往中间挤**，而分辨力正是这套评分方案唯一还能自证的东西。

**排名与 ChatGPT 不再完全一致**：V3 掉到最后并被判 drop。
从物理硬伤的角度这未必错（ChatGPT 也说 V3 要先修防水逻辑才考虑），
但它与「ChatGPT 给 V3 打 8.0、给 V1 打 7.6」的相对次序相反。

## 必须写清楚的方法论限制

**这是单次对单次，无法区分「改动的效果」与「回放噪声」。**
本仓库已经记录过：同一份输入三次回放，`verdict` 与 `recommendedOrder` 每次都不同。
所以：

- **可以归因于改动的**：V3 物理判定翻转、`setting_assumption` 被使用、
  `physicalAssumptions` 整块出现——这三件事在第一次的契约里根本不可能发生。
- **无法归因的**：分数收缩、排名变化、批次收敛翻转。它们**可能**是新增的物理审视
  拉低了整体判断，也**可能**只是两次回放之间的正常抖动。

要分开这两者，需要同一契约下重复回放取分布，而不是再改一次提示词。
**在拿到那组数据之前，不要因为这一次分数变窄就回头调权重或删掉物理审视。**

## 派生链第一次走到「全批淘汰」分支

四个全部 `drop`（6.13–6.89），于是 `recommendedWinner` 派生为空字符串、

## 两个必须记下的问题

**1. 简报判断方向与上一个包完全相反，而且与用户已确认的结论相左。**

- 包一：三个候选写 `suggestBriefChange`，方向是**放宽**——
  「把『外部奖励转赠长辈』放宽为『与亲密对象分享体验或劳动成果』」。
- 包二：四个候选全判 `WARN`，方向是**收紧**——
  「建议在 nonNegotiableExperience 中**强制要求保留**『外部奖励的获得与转赠』事件链」。

包二的说法与它自己的收敛结论有张力：这一批的病根是「身体拟物化」模板（它自己抓到了），
而不是「丢了奖励转赠」。而 ChatGPT 与用户已经判断过：**「外部奖励→转赠长辈」不应该是不可协商体验**。

**结论：`briefAlignment` / `briefProblemsDetected` 这一档目前不稳，不得当成改简报的依据。**
它值得看，但要人来判。

**2. 排名与派生总分不一致。**

`recommendedOrder` 是 V1 → V4 → V2 → V3，而分数是 V4 6.89 > V1 6.83。
模型推荐先做 V1，却给 V4 打了更高的分。

这说明**十一维加权分与模型的整体排名不是同一件事**。本版刻意没有为此加闸门
（两者都由模型给，强行对齐只会掩盖分歧），但它是「加权分到底在测什么」的一个直接证据，
应当进入那批要统计的数据。

# 抖动测量：同契约、同输入，每个包各 3 次

原始报告在 `抖动回放/`。上面那条「分数收窄是不是改动造成的」就是靠这组数据回答的。

## 包一《捐旧衣服》——有真实优劣差异的批次

| 候选 | 三次总分 | 极差 | 标准差 |
| --- | --- | ---: | ---: |
| V1 | 6.73 / 6.23 / 6.43 | 0.50 | 0.21 |
| **V2** | **8.06 / 8.29 / 8.15** | **0.23** | **0.09** |
| V3 | 6.73 / 7.53 / 6.48 | 1.05 | 0.45 |
| V4 | 7.83 / 7.59 / 6.75 | 1.08 | 0.46 |

- **V2 三次全排第一，分数 sd 只有 0.09。** 这是整套方案里最稳的信号，而且与外部评审的选择一致。
- V1 三次都在最低区间（sd 0.21），稳定垫底。
- **中间的 V3 / V4 抖得厉害**（sd 0.45 / 0.46），三次排序各不相同：
  `V2>V4>V1>V3` / `V2>V4>V3>V1` / `V2>V1>V4>V3`。

**结论：加权分能可靠地分出「最好的」和「最差的」，分不出中间的次序。**

# 这组数据带来的三处定型（当日落地）

**① 两个「谁更好」的系统拆开命名，都不删、也不强制对齐。**

```
scoreOrder                ← 服务端按十一维加权分派生（winner / runnerUp 从它来）
holisticPreferenceOrder   ← 模型看完之后凭整体判断给的顺序（原 recommendedOrder）
```

依据就是上面那两张表：加权分**能可靠分出最好与最差**（最佳候选 3/3 排第一、sd 0.09），
**分不出中间次序**（中段 sd 0.45–0.46）。而 winner 只取第一名，正好落在它可靠的那一段。

两份不一致**是有价值的观察，不是要消除的错误**——身体拟物那批里模型推荐先做 V1（6.83），
而 V4 分更高（6.89）。提示词明确告诉模型不必与评分一致、**不要为了看起来一致而回头改分数**；
页面在两者不一致时直接点出来。**中段排序不稳不打算修**：两个水平接近的创意本来就有审美随机性。

**② `briefAlignment` 正式降级为编辑参考信息，完全隔离。**
继续输出，但不参与分数、不参与 tier、不参与 verdict、不自动改简报、不作为定向修订的强制任务。
上面那张 PASS/WARN 翻转表就是依据。有测试锁住「改 `briefAlignment` 不改变任何派生结果」。

**③ `physicalAssumptions` 新增 `literalDependency`（`required` / `optional` / `make_believe`）。**
它与 `confidence` 是**两个正交的轴**：前者问「故事需不需要它真的成立」，后者问「现实里成不成立」。

起因是《罐装阳光》：把阳光装进玻璃罐在物理上当然 `unlikely`，但剧情从没要求它真成立——
而实测该候选被判 `conditional` 之后 `productionFeasibility` 9→7、`causalLogic` 9→8，
说明模型很可能把「不是现实物理」本身当成了质量问题。**那会把童真想象误杀。**
现在提示词写死：扣分只针对 `required` 且 confidence 不好的那些；`make_believe` 不得因为
现实做不到而扣制作可行性或因果逻辑，只提醒镜头别把它拍成实的（玻璃罐内部凭空发光）。
**没有新增闸门**——「有没有照此扣分」需要语义判断。

这三处**都还没有真实回放验证过**。下一次跑的时候要专门看：
两份顺序的分歧频率、`make_believe` 有没有被正确使用、《罐装阳光》的制作分是不是回到 8–9。
