## 一、机制池（两组共用）

从原片动作稿拆出的原子机制，要求每条**可以单独迁移**、且不含原片具体名词。

**[M1]**　`visual`　用夸张且符合角色特质的物理动作重新定义枯燥的日常任务，将劳作转化为游戏。

　　原片在哪兑现：咕嘎用身体趴着压平衣服，自称'咕嘎牌熨斗'。

**[M2]**　`visual`　通过两个角色在物理空间上的受力互补，无声展现共同目标的协作默契。

　　原片在哪兑现：糯糯在后推车，咕嘎在前拉车，共同运送装满衣服的纸箱。

**[M3]**　`escalation`　在主线任务的强制等待间隙，插入符合角色心智年龄的微型自发游戏，以调节叙事节奏并防止情绪断层。

　　原片在哪兑现：咕嘎和糯糯在回收站等待阿姨整理时，蹲在地上用粉笔画格子玩石子游戏。

**[M4]**　`payoff`　将抽象的外部认可转化为具象的、可附着于角色身体的物理标记，使成就感获得持续的视觉存在感。

　　原片在哪兑现：志愿者阿姨给咕嘎和糯糯胸前各别上一朵小红花作为捐赠奖励。

**[M5]**　`choice`　角色主动剥离代表自身最高成就的物理标记，并将其转移给默默付出的关爱者，完成情感的反向反哺。

　　原片在哪兑现：咕嘎和糯糯悄悄摘下自己胸前的小红花，别到奶奶的衣服上。

**[M6]**　`ending`　在叙事尾声使用空间上的物理远离，将角色间的微观情感互动融入宏观的环境氛围中，留下情绪余韵。

　　原片在哪兑现：结尾镜头拉远，展现夕阳余晖下院子里三人围坐吃饭的温馨全景。

### 逐轮判语

**A 组（自由挑）**

- 轮 1：这四个选题在‘解决路径’上最缺分化，多次依赖‘使用自身穿戴物作为物理屏障来应对环境干扰’的单一动作逻辑。
  - **V1 + V3**（解决路径）：任务目标受到自然环境（水坑/强光）威胁 → 角色脱下自身的衣物/配饰（校服外套/蓝色长围巾）作为物理屏障进行保护
- 轮 2：这四个选题在「任务性质与解决手段的匹配」上最缺分化，V1/V4陷入「社区劳作+游戏化协作+大人点赞」套路，V2/V3陷入「自然生物+随身道具保护+回归自然」套路。
  - **V1 + V4**（解决路径与情绪兑现方式）：面对社区公共服务任务 → 将枯燥劳作转化为童趣物理游戏并进行双人协作（袋鼠跳/拉推车 vs 纸箱升降台/递胶带） → 获得社区大人的具象化正向反馈（管理员给徽章 vs 大爷竖大拇指）
  - **V2 + V3**（解决路径与关键选择）：发现社区微小自然生物面临状况 → 利用随身衣物或道具进行非破坏性物理干预（反穿外套/树叶引导 vs 围巾帐篷/光环碰水） → 生物恢复自然状态（飞走/水珠滑落） → 角色在自然氛围中轻松收尾
- 轮 3：这四个选题在情绪兑现方式（尤其是结尾的视听环境渲染）上最缺分化，过度依赖“微风+风铃”的静态套路，且普遍未能兑现空间远离的机制要求。
  - **V2 + V4**（情绪兑现方式）：任务/事件平息 → 角色静止坐下 → 微风吹过触发风铃响 → 画面定格收尾

**B 组（预先规划）**

- 轮 1：这四个选题在将剧作机制直接转化为固定桥段时最缺分化，导致分配了相同机制的选题在因果链和情绪兑现上高度同质化。
  - **V2 + V4**（解决路径与情绪兑现方式）：遇到单人难以克服的物理操作难题（海报乱飞/水壶太重） -> 两人通过身体部位进行受力互补协作解决（猫压海报人刷胶/人抱把手猫托壶底） -> 任务完成后坐在长椅上镜头拉远融入环境氛围
  - **V1 + V3**（主要阻碍、解决路径与情绪兑现方式）：面临主线任务的强制等待间隙（等检查/等评选） -> 插入微型自发游戏度过等待（搭迷宫/跳房子） -> 获得具象的物理标记作为外部认可（贴纸/奖章）
- 轮 2：这四个选题在‘解决路径’维度上最缺分化，V1与V3同构于‘游戏化消解枯燥’，V2与V4同构于‘双人物理受力互补’，导致事件链高度同质化。
  - **V1 + V3**（解决路径）：面对枯燥/无聊的日常情境（值日/等车） → 角色主动将动作夸张化、游戏化（推冰壶/踢踏舞） → 在强制等待间隙插入微型游戏（抓光斑/手影） → 消解无聊获得愉悦。
  - **V2 + V4**（解决路径）：面对超出单人能力的物理重物（背景板/大拖把） → 两人采用物理空间上的受力互补姿势（前拉后推/反向拉锯） → 默契协作克服物理阻碍。
  - **V3 + V4**（情绪兑现方式）：任务完成后 → 角色在夕阳/晚霞下离开或告别 → 镜头从角色身上物理拉远，展现宏观城市/天空全景以留下情绪余韵。
- 轮 3：这四个选题在「情绪兑现方式」上最缺分化，过度依赖夕阳剪影拉远和向同伴转移头部佩戴物这两种固定视听与剧作范式。
  - **V3 + V4**（关键选择与情绪兑现方式）：获得成就标记（徽章/小红花） → 观察到同伴状态（累得睡着/毛发被吹乱） → 主动剥离自身标记并佩戴在同伴头部（卷发/猫耳）以完成情感反哺。
  - **V2 + V4**（情绪兑现方式）：主线事件收尾 → 镜头物理拉远 → 两人剪影融入夕阳/黄昏的宏观自然环境（校园全景/海岸铁道）以留下情绪余韵。

### 最关键的一条

B 组第 1 轮的判语：

> 这四个选题在**将剧作机制直接转化为固定桥段**时最缺分化，导致**分配了相同机制的选题在因果链和情绪兑现上高度同质化**。

第 2 轮说得更具体：**V1 与 V3 同构于「游戏化消解枯燥」，V2 与 V4 同构于「双人物理受力互补」**。

也就是说：**共享一条机制的两个候选，被写成了同一条事件链。**
模型把「机制」当成了「桥段模板」——M2「两个角色物理受力互补」三轮都被写成字面的「一起拉/抬/撑」。

前置分配把趋同**往后推了一步**，推到了「机制 → 桥段」这一层映射上。

## 五、结论

**做到了**：前置分配在约束层面完胜——覆盖满、无零引用、无子集、无重复组合，兑现率 64.3% → 91.7%。

**没做到**：约束分化**没有**换来剧情分化，B 组的实际重复反而比 A 组多。

**所以这一轮不足以支持落地。** 按「kernelFidelity 只查各自兑现、不参与排序」这个边界，
B 组 91.7% 不能读成「B 组更好」——它只说明模型更听话地把分配的机制写了进去，
而听话的方式恰恰是套用固定桥段。

**下一个要解决的问题已经定位清楚**：同一条机制可以有几种写法？
现在是一对一，所以分配不同机制也救不回来。
