# 对照实验：拿掉全部规则，只给数据（两轮）

2026-09-11。同一部参考片《帮奶奶捐旧衣服》，同一份上游 artifact，同一个 `qwen3.7-max`。
**唯一变量是提示词。两组各跑两次。**

| | A 组 | B 组 |
| --- | --- | --- |
| 提示词 | 现行 `variantsPrompt`（29,192 字 / 111 条否定式） | 只给数据（32,220 字 / 25 条否定式，且全来自数据本身） |
| 四份上游 | 投影过的删减版 | **完整 JSON** |
| 八维度差异 / ABC 矩阵 / 八项自检 / 生活质感 | ✅ | ❌ 一条不带 |

## 结果

### 指标一：「帮忙 → 获得奖励 → 转赠奶奶」完整链（契约上限 1 个）

| | 第 1 次 | 第 2 次 |
| --- | ---: | ---: |
| **B 组** 只给数据 | 4 / 4 | 2 / 4 |
| **A 组** 现行提示词 | 1 / 4 | 0 / 4 |

B 组第二次从 4/4 降到 2/4——**说明第一次那个满分有随机成分**。但两次都远高于 A 组，A 组两次都在上限之内。

### 指标二：末拍是不是「夕阳 + 三人吃饭」（这一条完美分离）

| | 第 1 次 | 第 2 次 | 合计 |
| --- | ---: | ---: | ---: |
| **B 组** | 4 / 4 | 4 / 4 | **8 / 8** |
| **A 组** | 0 / 4 | 0 / 4 | **0 / 8** |

**8 比 0。** 无规则那组八个候选无一例外收在「夕阳下三人围坐吃饭、镜头拉远」；
现行提示词那组八个里一个都没有。这比 ABC 稳定得多。

## 动作质感

**A 组主角在做的事：**

- 用双手给小苗**搭人肉帐篷挡风**，对着它嗷呜轻哼
- 趴在地上**鼓起腮帮子吹气**，想让落叶小船开动
- **给风筝的破洞贴创可贴包扎**，还对着它吹气止痛
- 蹲着**描自己影子的轮廓**，给影子头部画个大笑脸；**怕猫踩疼影子**，把猫抱开还揉了揉地上的影子
- 第二轮又出现：**靠在树干上睡着了，头顶的光环发出微弱的光**（这正是参考片《好朋友为你遮风挡雨》「主角睡到片尾」那种形状）

**B 组主角在做的事：**

- 整理 / 刷洗 / 踩扁 / 折纸 → 运送 → 鞠躬说「谢谢」→ 把奖励别在奶奶身上

八个候选里，主角本人的动作几乎一字不差。B 组不是没有具体动作，
但**具体的全在芙芙猫身上**（把书堆当滑梯、猫耳影子变狼、玻璃瓶当保龄球）。

## 结论

**那 111 条约束是在真实起作用的，我之前说它们「在事件层打转、保证不了好看」是错的。**

拿掉之后：四个候选塌成同一个故事，末拍 8/8 全是同一个画面，主角的性格动作整体消失。

能确认在起作用的：

- **ABC 布尔矩阵**（两轮 4/4、2/4 vs 1/4、0/4）
- **八维度根本差异**
- **`narrativeMode` 配比**（A 组两轮都有无任务的生活型，B 组八个全是任务型）
- **生活质感与萌点约束**（那五条动作，B 组一条都没有）

## 这个实验没有推翻的两件事

**① 长度不是规则的锅。** 精简版 32,220 字比现行的 29,192 还长——它给的是完整 JSON 而不是投影。
规则只占现行提示词 40%，数据占 55%，光角色边界一项就 42%。

**② 提炼层的问题还在。** A 组确实互不相同也确实有性格动作，但它们仍然是从「事件机制」推出来的。
`recastTest`（09-11 刚加）是第一个问「换个角色什么会塌」的字段，这两轮 A 组的简报里已经有它，
但它有没有真的改变候选质量，得和**没有它的那一轮**对照才知道——本实验没测这个。

## 限制

两轮不是统计。B 组 ABC 从 4/4 掉到 2/4 就是随机性的直接证据。
**但末拍那个 8:0 完美分离很难用随机解释**，而且方向与那几条约束的设计意图完全一致。
