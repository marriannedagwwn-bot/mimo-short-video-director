# 视频提示词书写攻略

本文只从 [`notes/raw-examples.md`](../notes/raw-examples.md) 中归纳有教程实例支撑的写法。模板中的方括号表示可替换字段；教程没有明确说明适用模型时，一律标为“未说明”，不把示例自行外推到可灵、即梦、Veo 或 Sora。

## 一、字段记法

```text
[字段]       必填或按需求填写的内容
[字段A / 字段B]  二选一
（可选：[字段]）  没有该需求时可以删除
@素材名      在支持多模态引用的平台中绑定图片、视频或音频
```

## 二、基础生成模板

### 模板 1：先生成视频所需的参考图

- 适用任务：角色图、场景图、首帧概念图。
- 适用模型：图片生成模型——未说明；可灵 / 即梦 / Veo / Sora——不适用，本模板不是视频生成指令。

```text
[时间与光线]，[主体身份与外观]，[主体姿态与表情]。[场景与前后景动态]。[风格与色调]。[景别]，[取景范围]，[机位角度]。
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[时间与光线]` | 傍晚、夕阳暖光、天空青色 |
| `[主体身份与外观]` | 年龄、国别/文化身份、服装、发型、道具 |
| `[主体姿态与表情]` | 站立、看向远方、悲伤但不落泪 |
| `[场景与前后景动态]` | 竹林、风吹衣服、前景竹叶飞过 |
| `[风格与色调]` | 电影质感、绿色调、孤独感 |
| `[景别/范围/角度]` | 中景、膝盖以上、微微仰视 |

规则：先把视频第一眼必须稳定的主体、场景、风格和构图写进参考图提示词，减少后续视频模型自行猜测。

教程真实示例（`01-图片提示词.mp4`，`08:30–09:16`）：

```text
傍晚，天边泛着一点微弱夕阳的暖光，天空上方泛着一点青色，夕阳微微洒在角色身上。一名中国武侠老人，穿着华丽的白色武侠服装，一只手里握着一把宝剑，宝剑收入剑鞘之中。他白发苍苍，白色胡须很长，但是眼睛炯炯有神，头发也整理得很整齐。他静静站着，做出看着远方的姿势和表情。他的衣服被风微微吹拂。他站在竹林之上，周围是绵绵不绝的竹林，风中吹过一些竹叶，前景有几片快速飞过的竹叶。整张图片风格参考《卧虎藏龙》的电影质感，绿色调，显示孤独的感觉。中景，只展现角色的膝盖以上，微微仰视。
```

### 模板 2：图生视频的最小结构

- 适用任务：已有主体图片，只需要补动作与镜头。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[主体] + [主体动作] + [镜头运动或稳定方式]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[主体]` | 红色机器人、画面中的白马 |
| `[主体动作]` | 扭头、打招呼、抬起前蹄 |
| `[镜头运动或稳定方式]` | 固定镜头、缓慢推进、缓慢拉远 |

规则：最少要把“谁动、怎么动、摄影机怎么动”写清楚。

教程真实示例（`02-视频生成.mp4`，`01:44–02:08`）：

```text
红色机器人扭头对着镜头打招呼，固定镜头
```

### 模板 3：文生视频的完整起步结构

- 适用任务：没有输入图片，直接从文字生成视频。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[时间]，[主体]，[主体所在位置]，[背景环境]，[构图/机位]。[运镜]，[天气或环境变化]，[切镜与景别]，[主体动作、表情和可见结果]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[时间]` | 白天、清晨、日落时分 |
| `[主体所在位置]` | 站在城市马路上 |
| `[背景环境]` | 城市废墟、玻璃反射的高楼 |
| `[构图/机位]` | 半侧面平视图 |
| `[运镜]` | 缓慢推进 |
| `[环境变化]` | 晴天变阴天并下雨 |
| `[切镜与景别]` | 切镜头，特写脸部 |
| `[动作与结果]` | 眼睛逐渐变红、雨水流过脸部 |

规则：文生视频先交代静态画面内容，再接视频中的动作、变化和镜头。

教程真实示例（`02-视频生成.mp4`，`14:33–15:08`）：

```text
白天，一台红色机器人，站在城市的马路上，背景是城市的废墟，城市是高楼大厦，有很多玻璃反射的高楼大厦的感觉，半侧面平视图。镜头缓慢推进，天上从晴天变成阴天，下雨，切镜头，特写，机器人的脸部，它的眼睛逐渐变红，似乎具有攻击性，雨水顺着它的脸上流下来
```

## 三、动作与角色控制模板

### 模板 4：把抽象情绪翻成可见动作

- 适用任务：需要模型表现害羞、疲惫、外向等性格或情绪。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[主体]像[性格/情绪参照]一样，[脚部动作]，[腿部动作]，[肩部动作]，[手部动作]。它先[动作1]，[动作2]，随后[动作3]，显得[目标情绪]。[镜头方式]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[性格/情绪参照]` | 害羞的小姑娘、电量不足 |
| `[身体动作]` | 双脚内八、肩膀缩起、双手贴在身前 |
| `[动作1…3]` | 低头躲镜头、犹豫、慢慢看向镜头、挥手后收回 |
| `[目标情绪]` | 羞涩扭捏、疲惫、兴奋 |

规则：不要只写情绪名，要把情绪拆成身体部位、动作顺序、幅度和速度。

教程真实示例（`02-视频生成.mp4`，`02:47–03:01`）：

```text
机器人像害羞的小姑娘一样扭捏地站着，双脚内八，膝盖微微并拢，肩膀缩起，双手贴在身前。它先低头躲开镜头，轻轻晃一下身体，犹豫后慢慢转头看向镜头，在胸前小幅挥手打招呼，随后立刻收回手，显得非常羞涩扭捏。固定镜头
```

### 模板 5：多主体动作分配

- 适用任务：同一画面中有两个或更多主体。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[主体A]用[声音]说：“[对白]”。[主体A动作与情绪]。[主体B]执行[动作链]并发出[声音]。[镜头方式]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[主体A/B]` | 红色机器人、白马 |
| `[对白]` | 角色要说的原句 |
| `[动作链]` | 抬前蹄 → 后腿站立 → 仰天嘶鸣 |
| `[声音]` | 机器人的语音、嘶鸣 |

规则：每个动作和声音都要紧邻执行它的主体，不能只列动作而不写归属。

教程真实示例（`02-视频生成.mp4`，`03:12–03:34`）：

```text
红色机器人用机器人的语音说：“你好，我是Tim，你喜欢这套AI影像课程吗？”它对着镜头打招呼，显得很开心。让画面中的白马站在地面上，缓慢抬起前蹄用后腿站立，仰天嘶鸣。固定镜头
```

## 四、摄影控制模板

### 模板 6：复杂运镜路径

- 适用任务：需要明确起点、运动轨迹、机位变化和终点构图。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[主体状态]。[摄影设备/视角]，[稳定性或运动质感]。镜头先[方向、速度与起始机位]，[停顿]。随后[方向与速度变化]，最终[终点机位与构图]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[主体状态]` | 一动不动、向前奔跑 |
| `[摄影设备/视角]` | 机械臂、FPV、手持 POV、肩扛手持 |
| `[运动质感]` | 无抖动和惯性、横滚倾斜、运动模糊 |
| `[路径]` | 左前方 → 右上角 → 主体左前方 |
| `[终点构图]` | 高机位全身、面部特写 |

规则：复杂运镜要写出运动顺序，至少包含起始运动、方向/速度变化和最终构图。

教程真实示例（`02-视频生成.mp4`，`06:00–06:12`）：

```text
红色机器人一动不动。机械臂程序控制运镜，点到点精确关键帧，无抖动和惯性。镜头先快速向左前方移动，以极低角度仰视机器人右侧全身，短暂停顿。随后镜头像执行预设关键帧一样突然向右上角加速，沿着机器人正面移动到它的左前方，变成高机位全身构图
```

### 模板 7：焦点转移

- 适用任务：固定镜头内仍需要视觉变化，或需要把注意力从背景移到主体。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[主体状态]，一开始[主体/前景]是模糊的；[背景/另一主体]是清晰的。然后变成[背景/另一主体]是模糊的，[主体/前景]变清晰了。[镜头方式]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[起始焦点]` | 背景清晰、机器人模糊 |
| `[结束焦点]` | 背景模糊、机器人清晰 |
| `[镜头方式]` | 固定镜头 |

规则：焦点变化要同时写出开始和结束时谁清晰、谁模糊。

教程真实示例（`02-视频生成.mp4`，`07:42–07:54`）：

```text
红色机器人一动也不动，一开始红色机器人是模糊的；背景是清晰的。然后变成背景是模糊的，红色机器人变清晰了。固定镜头
```

### 模板 8：环境或时间变化

- 适用任务：主体保持不动，但让天气、昼夜、季节、色调或背景事件发生变化。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[主体状态]，[镜头方式]。[环境维度]从[起点状态]变成[终点状态]，（可选：[终点光源或可见结果]）
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[环境维度]` | 时间、天气、季节、色调、背景建筑 |
| `[起点状态]` | 白天、晴天、夏天、暖色调 |
| `[终点状态]` | 黑夜、下雨、冬天、冷色调、发生爆炸 |
| `[终点光源或结果]` | 只有月光照耀废墟、玻璃碎片飞散 |

规则：环境变化要写明变化维度、起点和终点；需要稳定主体时，同时重申主体与镜头不动。

教程真实示例（`02-视频生成.mp4`，`08:27–08:31`）：

```text
机器人一动不动，固定镜头。让时间从白天变成黑夜，只有月光照耀着城市废墟
```

## 五、时间、剪辑与声音模板

### 模板 9：单段视频内的分镜链

- 适用任务：希望一次生成包含多个景别或切镜。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[镜头1运镜与环境变化]；切镜头，[景别2]，[主体部位与动作]；切镜头，[景别3]，[主体部位与动作/焦点变化]；切镜头，[返回构图]，[结尾运镜与事件]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[景别]` | 特写、大远景、回到最开始的镜头 |
| `[主体部位]` | 脸部、拳头 |
| `[焦点变化]` | 先模糊，焦点给到拳头后变清晰 |
| `[结尾事件]` | 镜头拉远、天空打雷 |

规则：每次“切镜头”后立即写新景别、新主体或部位，以及该镜头内发生的动作。

教程真实示例（`02-视频生成.mp4`，`13:04–13:42`）：

```text
镜头缓慢推进，天上从晴天变成阴天，下雨；切镜头，特写，机器人的脸部，它的眼睛逐渐变红，似乎具有攻击性，雨水顺着它的脸上流下来；切镜头，特写，机器人的手捏紧了拳头，一开始拳头是模糊的，焦点给到拳头，拳头变成清晰的；切镜头，回到最开始的镜头，大远景，镜头缓慢拉远，天上突然打雷了
```

### 模板 10：按节拍组织长动作链

- 适用任务：一镜到底、延时、慢动作、变速或多个连续阶段。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明。

```text
[音乐约束]，[连续性要求]，[镜头方式]，[主体初始状态与最终状态]。
节拍1：[事件、动作、速度效果与可见结果]。
节拍2：[承接状态、时间/环境变化与可见结果]。
节拍3：[主体动作链、速度效果与最终状态]。
[全程必须保持的构图、主体和停止条件]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[连续性要求]` | 连续一镜到底、不切镜头 |
| `[主体初始/最终状态]` | 开始完全静止、结尾挣脱 |
| `[速度效果]` | 慢镜头、快速延时、变速镜头 |
| `[承接状态]` | 保持上一阶段大楼部分坍塌的状态 |
| `[停止条件]` | 主体直到最后一刻才动作 |

规则：长动作链用编号节拍固定先后关系，并在下一节拍写明要继承的上一阶段状态。

教程真实示例节选（`02-视频生成.mp4`，`08:48–08:57`）：

```text
无音乐，连续一镜到底，全程固定镜头，机器人始终站在画面中央，开始完全静止，直到结尾挣脱。
节拍1：城市大楼各处突然发生爆炸，火光四射，冲击波扩散，玻璃碎片飞向空中，前景也有火光。画面进入慢镜头，碎玻璃在空中缓慢旋转，大楼部分坍塌。烟尘缓缓扩散。
节拍2：镜头不切换，场景进入废弃城市的快速延时变化，保持前面建筑爆炸后部分坍塌的状态。
节拍3：变速镜头。植物从地面裂缝、墙面和周围废墟中自然生长出来，藤蔓、枝叶和根须沿着机器人的双腿、腰部、身体和肩膀不规则地向上攀附和缠绕，层层蔓延，将机器人逐渐覆盖。机器人保持一动不动，双眼突然亮起强烈红光。短暂停顿后，机器人猛然挺身，肩膀和双臂同时向外一震，缠绕身体的所有藤蔓、根须和青苔在同一瞬间全部绷断并向四周弹飞，露出机器人的本体。
```

### 模板 11：纯音效与空间声场

- 适用任务：不生成配乐，只控制动作声、环境声和画外声。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明是否都支持原生音频生成。

```text
纯音效设计，无配乐。[主体动作]，[近处动作声的音量、音色和组成]，[声音随距离的变化]。随后[环境事件]，[事件声的先后层次]。[声源方向、距离、空间感与余响]
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `[动作声]` | 脚步、金属关节、液压驱动、地面震动 |
| `[环境事件]` | 大楼爆炸、玻璃碎裂、结构坍塌 |
| `[声源空间]` | 从远处建筑后方传来、逐渐远离画面 |
| `[声音尾部]` | 余震和碎片掉落声持续回荡 |

规则：声音提示词要写音源、声响组成、远近方向和衰减/回响，同时明确是否要配乐。

教程真实示例（`02-视频生成.mp4`，`09:54–10:02`）：

```text
纯音效设计，无配乐。红色机器人开始迈着沉重的机械步伐向画面右边走出画面，脚步声巨大、低沉，每一步都有金属关节运转声、液压驱动声和地面震动声，脚步逐渐向画面外远离。随后后方大楼突然猛烈爆炸，先是低频冲击波轰鸣，然后是玻璃大面积碎裂飞散、金属结构撕裂、混凝土坍塌、碎石落地和烟尘翻涌的声音。爆炸声具有强烈空间感，从远处建筑后方传来，余震和碎片掉落声持续回荡
```

## 六、参考素材模板

### 模板 12：用图片锁定角色细节

- 适用任务：文生视频时，用多角度图和特写图保持角色外观。
- 适用模型：可灵 / 即梦 / Veo / Sora / Seedance 2.0——未说明；且不同平台的素材引用语法可能不同。

```text
[完整文生视频提示词]。[主体]的细节参考@图片1和@图片2
```

可替换字段：

| 字段 | 可填写内容 |
|---|---|
| `@图片1` | 主体四视图 |
| `@图片2` | 主体脸部特写或局部细节图 |
| `[主体]` | 必须与正文中的主体名称一致 |

规则：需要外观一致性时，在完整视频提示词中明确把角色细节绑定到对应参考图。

## 七、教程说法冲突：必须二选一

以下不是统一结论，而是教程中不能同时作为普遍规则使用的两组说法。

### 冲突 1：详细锁定，还是让模型自行组织

| 立场 | 教程原话所支持的做法 | 真实示例 |
|---|---|---|
| `01-图片提示词.mp4` | 提示词越明确，AI 越不需要猜测，结果越稳定。 | `特写角色的脸部，50mm 镜头，光圈 f/2.8，浅景深`（`10:19–10:34`） |
| `03-全能参考视频提示词.mp4` | 用朋友能听懂的故事描述加类型与质感，让 Seedance 2.0 自行组织电影化画面和镜头。 | `大雾天的城市清晨，一只巨型水母从浓雾中飘出……`（`02:34–03:06`） |

冲突结论：前者要求增加控制信息，后者主动把镜头组织权交给 Seedance 2.0。两个教程没有给出统一优先级，不能把它们写成“所有模型都应尽量详细”或“所有模型都应只写大白话”这一条通用规则。最终人工确认：使用第一条结论

### 冲突 2：单段禁配乐，还是在生成时绑定背景音乐

| 立场 | 教程原话所支持的做法 | 真实示例 |
|---|---|---|
| `02-视频生成.mp4` | 每段生成时通常关闭音乐，剪完画面后统一配乐，避免多段 AI 音乐互相冲突。 | `不要生成音乐`（`09:03–09:09`） |
| `03-全能参考视频提示词.mp4` | 在多素材提示词中直接指定背景音乐素材。 | `背景音乐使用 @这段音乐`（`06:13–07:40`） |

冲突结论：同一条成片流程不能既要求“本段无音乐”又要求“使用指定背景音乐”。教程没有规定哪一个优先，实际写提示词前必须选择“后期统一配乐”或“生成时绑定音乐”其中一种。最终人工确认：使用第一条结论

### 3. 组合后的完整提示词

```text
黄昏，一台锈迹斑斑的红色机器人低头站在废弃城市的十字路口，四周是破碎的玻璃高楼。机器人开始完全不动，双眼熄灭。无配乐，只保留现场环境声和动作声。

镜头1：固定大远景，保持机器人站在画面中央。天空从晴天迅速变成阴天，暴雨落下，远处闪电照亮城市废墟。机器人继续一动不动，雨水沿着它的头部、肩膀和手臂流下。声音是密集雨声、低沉雷声和远处玻璃坠落声。

全程保持同一座废弃城市、同一台红色机器人和连续一致的暴雨状态；机器人在双眼亮起之前身体完全不动；不新增其他人物、车辆或背景音乐。
```
