# 首页面板等高与候选按钮对齐

用户要求：参考视频面板与右侧创作设置面板等高，优化左侧间距；每排候选卡片的「进入完整剧情」按钮底部对齐。

改前直接测量用户当前页面（1669 × 1538 CSS 像素）：左面板高 955.12px，右面板高 1035.42px，相差 80.30px；两排候选按钮底边分别相差 53.78px、38.99px。

原因与最小改动：工作区网格的 `align-items: start` 阻止面板拉伸；候选按钮处于普通文档流。改为网格拉伸和纵向 flex，字幕区、候选动作列表分别吸收剩余高度。动作列表保留自然行距，按钮仍保留 14px 上间距。左面板各主要区块统一为 24px 间距，字幕框最小高度 140px，行高 1.65；只有桌面上传或已加载媒体状态分配额外高度。窄屏保留自然高度，并允许长文件名收缩、候选头部换行；结果列表的单列轨道使用 `minmax(0, 1fr)`，避免其他内容的最小宽度撑宽候选卡片。
